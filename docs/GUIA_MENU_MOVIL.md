# Corrección del menú móvil

Esta actualización refuerza la navegación lateral en celulares.

## Comportamiento

- El botón de menú abre la barra lateral.
- Se muestra un fondo semitransparente detrás del menú.
- Tocar fuera del menú lo cierra.
- Elegir una sección cierra el menú automáticamente.
- La página no se desplaza mientras el menú está abierto.
- La tecla Escape también cierra el menú en dispositivos con teclado.

## Archivos modificados

- `index.html`
- `css/app.css`
- `js/main.js`
- `js/ui.js`

No requiere cambios en Supabase.
